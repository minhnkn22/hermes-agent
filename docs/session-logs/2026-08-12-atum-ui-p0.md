# Atum desktop P0 UI handoff — 2026-08-12

## Context

This checkpoint implements the bounded P0 portion of the accepted Opus UI
handoff on `feat/atum-ui-p0`, based exactly on Hermes commit
`057d5b11a82ee4e166e870f4ba7a4ea629773fb3`. The durable Opus planning job is
`44a15ab2-1d73-4302-a161-168636cc8de7`.

The work is renderer-only. It does not change messaging stores, backend
runtime or packaging, hosted Atum services, routes, provider integrations, or
Hermes capability surfaces.

## Behavior delivered

- Replaced the globally suppressed keyboard outline with a designed
  `:focus-visible` token while keeping text-entry controls visually stable.
- Consolidated the profile switcher into the top of the existing navigation
  rail. Profile selection, drag ordering, pinning, aliases, color editing,
  creation, deletion, the condensed-profile path, contributed navigation, and
  every existing route remain available.
- Gave new-session and messaging destinations distinct add and radio-tower
  semantics, added navigation/list landmarks, and exposed the current route.
- Restored the Atum brand mark and calm wordmark treatment on the empty thread.
- Added the locked Vietnamese P0 shell, onboarding, chat, recovery, tool,
  approval, and status copy with deterministic assertions for the exact
  founder-approved strings.
- Made failed tool rows open by default, kept backend error details visible,
  and exposed retry/reload actions for failed turns.
- Added a non-modal post-boot offline banner whose Retry action reconnects
  through the existing gateway hook, while preserving the existing cold-boot
  and boot-failure paths.
- Added an empty-conversation recovery CTA that starts a conversation rather
  than creating a project.
- Centralized reduced-motion detection and disabled decorative animation,
  animated loading dots, session-settle scrolling, and timeline jump animation
  when the OS preference is enabled.
- Improved the live thread, assistant busy state, approval alert dialog,
  keyboard focus restoration, status shape/labels, composer shortcut metadata,
  and error recovery semantics for assistive technology.
